\section*{Selected Research Contributions}
\begin{itemize}
\item \textbf{Decision-aware fleet rebalancing:} Designed an operational-target learning framework that trains vehicle-coverage decisions using delayed service and vehicle-reuse outcomes; combined counterfactual replay with selected-basis LP sensitivity, preserving exact integer-feasible network-flow execution.
\item \textbf{Probabilistic platform demand modeling:} Developed models for sparse and correlated ride-sourcing demand using zero-inflated count distributions and noncrossing multi-quantile forecasts; evaluated predictive accuracy and uncertainty calibration on operational trip data.
\item \textbf{Transportation network inference:} Developed a closed-loop framework to infer network-wide origin--destination travel times from incomplete and delayed endpoint observations using low-rank representations, latent dynamics, and adaptive filtering.
\end{itemize}
